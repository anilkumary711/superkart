# SuperKart Sales Planner

Upload the contents of this folder to a separate Blank Docker Space.
Set the environment variable BACKEND_URL to the Flask Space's actual HTTPS application URL.
For local Docker Compose, this is set automatically to http://backend:7860.

The interface supports single predictions, CSV batch upload and result download.
